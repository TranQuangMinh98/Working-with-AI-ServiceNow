Plugins & Apps You Need

Reference Document · Everything you install (or enable) to work through this course, mapped to the lessons that use it.
⚠ Always verify against your release notes. Store-app names, version numbers, and dependencies change every release. The names below are verified for the Yokohama → Zurich era (2025–2026). Confirm exact versions for your instance before installing. When in doubt, install the parent app and let its dependencies pull in automatically.
The three-layer mental model (from Lesson 4): License / SKU (permission to use Now Assist) → Plugins & store apps (the AI Agents + Skill Kit software) → Platform features (AI Search + the panel that surfaces agents). All three layers must be in place before an agent will run.

1. Core Store Apps (Required)

Install these from the ServiceNow Store. They are the software that makes AI Agents exist on your instance.

App / PluginWhat it gives youUsed in
Now Assist AI Agents Required The core AI Agents capability — AI Agent Studio, the sn_aia_agent / sn_aia_usecase tables, and the orchestrator. Units 1–6 (everything)
Now Assist for [product] Required
e.g. Now Assist for ITSM / HRSD / CSM		 Product-specific pre-built agents, skills, and the Now Assist Panel integration for that product. Pick the one matching your work. Unit 3 (pre-built agents)
Now Assist Admin (Console) Required Where you manage model providers per skill/skill-group/instance. Must be v6.6.4+ or Studio throws "Security constraints prevent access". Lessons 6, 15 (model provider)
Now Assist Skill Kit (NASK) Required for custom skills Build custom generative-AI skills. Needs the sn_skill_builder.admin role. Not on PDIs. Lesson 14 (Skill Kit)

2. Platform Features to Enable (Required)

These ship with the platform — you don't install them from the Store, you turn them on.

FeatureWhy it's neededUsed in
AI Search Required Powers retrieval / RAG tools and agent grounding. Agents that look up knowledge won't work without it — a common cause of "No agents available". Lessons 7, 12 (tools)
Now Assist Panel / Otto Panel Required The in-product side panel where users actually talk to agents. If it's off, deployed agents have nowhere to appear. Lessons 5, 18 (deploy)
Flow Designer / Workflow Studio Bundled Ships with the platform. Used to build subflows that agents call as tools, and to trigger agentic workflows. Lesson 16 (workflows)
Virtual Agent Optional An additional channel to surface agents in a chat experience. Lesson 18 (channels)

3. BYOK / External Model Provider Stack (Optional)

Only needed if you want to use an external LLM (Claude, GPT, Gemini) instead of the Now LLM Service — the subject of Lesson 15.

App / PluginWhat it gives youUsed in
Generative AI Controller BYOK The connector layer for external LLMs (BYOK/BYOLLM). Keep it on the latest compatible version, or provider settings silently revert after an upgrade. Lesson 15 (BYOK)
Provider spoke BYOK
Amazon Bedrock / Azure OpenAI / Google Vertex		 The integration to your chosen provider. Anthropic Claude is reached via the Amazon Bedrock spoke; GPT via Azure OpenAI; Gemini via Google. Lesson 15 (BYOK)
Supported orchestration providers (Yokohama P6+ / Zurich P1+): Now LLM Service (default), Azure OpenAI (GPT‑4.1 / 4.1‑mini), Anthropic Claude (on AWS Bedrock), and Google Gemini 2.5. Provider support is set per skill — there is no per-agent orchestration override yet. See Lesson 15.

4. Health-Check Tool (Recommended)

  • Now Assist Readiness Evaluation — a store app that scans your instance and tells you what's missing for AI Agents. Run it before you start building to catch license, plugin, and feature gaps early.
⚠ Licensing gate: AI Agents require an active Now Assist license at the Pro Plus or Enterprise Plus SKU — layered on your product (ITSM, CSM, HRSD…). No SKU, no agents, regardless of which plugins are installed.
