Common Problems & Fixes

Setup & Access

"Security constraints prevent access to requested page" After upgrade

Symptom AI Agent Studio or Now Assist Skill Kit throws this error right after you updated the Now Assist AI Agents store app.
Cause The Now Assist Admin Console store app wasn't updated to a compatible version alongside it.
Fix Update the Now Assist Admin Console store app to v6.6.4 or later, then reload Studio.

Can't access AI Agent Studio at all Setup

Symptom The Studio menu is missing, or opening it is blocked.
Cause Missing role, missing entitlement, or an out-of-date Gen AI Controller.
Fix Confirm you hold the sn_aia.admin role; verify your instance has a Pro Plus / Enterprise Plus Now Assist SKU; repair the plugin; and check the Generative AI Controller version. (Lesson 6)

Can't build on a Personal Developer Instance (PDI) Very common

Symptom You want to practice on a free PDI, but Skill Kit / full agent building isn't there.
Cause AI Agents and the Now Assist Skill Kit are not available on PDIs — they need an enterprise instance with Now Assist entitlements.
Fix Use an enterprise/customer instance with the right SKU. On a PDI you can still learn the concepts, but you can't fully build. (Lesson 4)

Agents stop responding after a patch or upgrade Very common

Symptom After a patch, agents don't respond, skills aren't discovered, or Studio throws errors.
Cause You updated individual child plugins instead of the parent, leaving the dependency chain inconsistent.
Fix Always update the parent plugin (e.g. "Now Assist for ITSM") so updates cascade to its dependents. Re-check for updates after every patch.

Agent Won't Run / Isn't Found

"No agents are available at the moment" Very common

Symptom The panel says no agents are available even though you built one.
Cause Usually agent proficiency / description not filled in or too vague; also AI Search not enabled, orchestrator token count exceeded, or the agent/tools aren't Active.
Fix Write a clear, specific name + description; enable AI Search; confirm the agent and every tool/skill it uses are Active. (Lessons 10, 12)

Prebuilt agent hangs at "Task Start" Setup

Symptom Testing a pre-built agent hangs at "Task Start", often a 500 error in the console. Reinstalling doesn't help.
Cause The underlying assistant is inactive — not flagged as a prerequisite in the docs.
Fix Go to Conversational Interfaces > Assistant Designer > Assistants, activate the assistant tied to your setup, then retest.

Trigger built, but the workflow never fires Very common

Symptom You added a record/schedule trigger, but nothing happens when the event occurs.
Cause Triggers deploy inactive. They must be manually activated after testing.
Fix Open the trigger and activate it once testing is done. (Lessons 3, 18 — see the Glossary entry for "Trigger".)

Agent task doesn't execute for some users Access

Symptom A workflow runs for you (admin) but not for real users.
Cause The workflow/agent is acting on a record the user doesn't have access to (ACLs / domain / scope).
Fix Test as the target user, check ACLs and the securityAcl on the agent, and rule out domain-separation / scope issues. Read the AI decision logs.

Agent stops re-using a tool mid-run Config

Symptom The agent calls a tool a few times, then refuses to call it again.
Cause The continuous-execution guardrail was hit.
Fix Check the sn_aia.continuous_tool_execution_limit property — it caps uninterrupted repeat calls to the same tool.

Model Provider

Your provider isn't in the list / agent fails silently after save Common

Symptom The model provider you want (Claude, GPT, Gemini) doesn't appear during configuration, or the agent fails silently once saved.
Cause Some skills and agentic workflows have provider restrictions not shown in the UI. Supported set: Now LLM, Azure OpenAI, Google Gemini, Anthropic Claude (AWS).
Fix Check the model provider support matrix for your specific skill type, release, and market before configuring. (Lesson 15)

LLM provider setting reverts hours after an upgrade Common

Symptom You set a preferred provider; within hours it silently reverts, often unnoticed until an agent fails.
Cause The instance was upgraded without updating the Generative AI Controller and Now Assist Admin apps; older versions reset the config.
Fix Update both store apps to the latest compatible versions before configuring. On Zurich Patch 6 or earlier, move to Patch 7+ for a permanent fix.

Forms & UI Actions

UI action added as a "channel" doesn't show on the form Very common

Symptom You added a UI action in the workflow's channel section, but no button appears on the Incident form.
Cause Listing a UI action as a channel does not create or bind a button. The button is a separate sys_ui_action record that must independently qualify to render, and a system property gates agentic-workflow actions.
Fix Enable the property com.glide.agentic_processes_view.enabled = true (create it if missing), then reopen the record. Also confirm the UI action is Active, on the right table, has a Form button/link checkbox on, and its condition passes for you. Check classic vs. Workspace — they surface actions differently. To actually trigger the workflow, the UI action needs a server-side script that calls it.

UI action shows in classic UI but not in Workspace (SOW) Common

Symptom The button appears on the classic form but is missing in Service Operations Workspace.
Cause Workspace only renders UI actions explicitly enabled for it, and only supports form buttons + menu items.
Fix Enable the UI action for Workspace (declarative action / "Workspace form button"), and ensure an action bar is present on the Workspace form.

Behavior & Quality

Same prompt gives different results Expected

Symptom Identical inputs produce different agent behavior run to run.
Cause Not a bug — AI Agents and generative AI are non-deterministic systems.
Fix Tighten instructions, add guardrails/approval gates, and test across many runs rather than expecting one fixed answer. (Lessons 10, 15)

Orchestrator "token count exceeded" / slow, expensive runs Performance

Symptom Runs fail on token limits or feel slow on data-heavy tasks.
Cause Too many tools per workflow, or heavy data analysis done through raw LLM calls.
Fix Keep to ≤ 15 tools/agents per use case; for data-heavy analysis, build a Skill (NASK) to limit LLM calls. (Lessons 14, 17)

Now Assist Panel times out after 2 hours Config

Symptom The panel conversation goes dead after a couple of hours.
Cause Idle-timeout settings.
Fix Adjust Conversation Idle Timeout on the Now Assist Panel (sys_cs_channel) record and the com.glide.cs.conversation_idle_timeout property.
