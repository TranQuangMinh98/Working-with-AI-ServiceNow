Lesson 10: Writing Effective Instructions

Duration: 15 minutes | Level: Beginner | Prerequisites: Lesson 9

Learning Objective

Write agent instructions that are assertive, unambiguous, and tool-aware — the difference between an agent that reliably does its job and one that wanders.

The Core Principle

"If you don't know what you want, the agent won't know what you want." Instructions must be assertive and unambiguous. Vague instructions produce vague, inconsistent behavior. (ServiceNow walkthrough)

Five Rules for Good Instructions

1. State exactly what you expect as output

Don't say "help with incidents." Say "Return the incident number, priority, and assigned group as a short bulleted list."

2. Tell the agent WHEN to use each tool

Every time you add a tool, add a line to the instructions describing when to invoke it. An agent that doesn't know when to use a tool won't use it — or uses it at the wrong moment.

3. Encode approval gates for risky actions

For autonomous write tools, spell out the guardrail explicitly:

NEVER modify or close a record without
first getting explicit user approval.
Always show the user what you plan to
change and wait for a "yes".

4. State naming conventions and data boundaries

Tell the agent which tables it may touch, which it must never touch, and any naming rules it should follow. Boundaries prevent surprises.

5. Keep it to one capability

Instructions for a focused agent are short and clear. If your instructions are sprawling across many unrelated jobs, split the agent.

Before & After

❌ Weak: "You help users with their tickets and do stuff with incidents and other things they need."
✓ Strong: "You are an incident triage assistant. When a user reports an issue: (1) look up their open incidents using the lookup tool; (2) if none match, create one with the create tool, setting category from their description; (3) always confirm the details with the user before creating. Return the new incident number. Never modify existing incidents without approval."
Remember the ReAct loop: The agent reasons in Thought → Action → Observation cycles (Lesson 15). Good instructions guide each Thought toward the right Action. Think of instructions as coaching the agent's thought process.
Official guidance: ServiceNow publishes dedicated pages titled "Writing effectively for agentic AI" and "AI agents best practices" in the Zurich docs. Consult them as your instruction-writing reference.
