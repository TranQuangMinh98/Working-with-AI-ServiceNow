Lesson 4: Prerequisites, Plugins & Licensing

Duration: 15 minutes | Level: Beginner | Prerequisites: Unit 1

Learning Objective

Know exactly what your instance needs before you can build AI agents: the right release, license, plugins, and platform features.

⚠ Always verify against your release notes. Plugin names, patch requirements, and entitlements evolve every release. The items below are verified as of the Yokohama/Zurich era (2025) — confirm the specifics for your instance's version before you begin.

1. Release Version

AI Agents became natively available in Yokohama (early 2025) and were deepened in Zurich (late 2025). A commonly cited baseline is Zurich Patch 2+ or Yokohama Patch 8+ (latest patch recommended). The Now Assist Skill Kit (NASK) shipped earlier, in Xanadu.

2. Licensing / Entitlement

AI Agents require an active Now Assist license. This is a paid entitlement layered on the relevant product (ITSM, CSM, HRSD, etc.).

⚠ Not on PDIs: The Now Assist Skill Kit is not available on Personal Developer Instances. Full agent building needs an enterprise instance with Now Assist entitlements.

3. Plugins & Apps to Install

From the ServiceNow Store, you'll typically need:

  • Now Assist AI Agents — the core AI Agents capability
  • Now Assist for [product] — e.g. Now Assist for ITSM / HRSD / CSM
  • Now Assist Skill Kit — to build custom skills (Unit 5)
  • Their dependencies, installed automatically with them

4. Platform Features to Enable

  • AI Search — enabled (required for retrieval/RAG tools and agent grounding)
  • Now Assist Panel (a.k.a. Otto Panel in Zurich) — enabled, so users can reach agents

The Pre-Flight Checklist

  1. ☐ Instance on a supported release + patch (verify in release notes)
  2. ☐ Active Now Assist license for your product
  3. ☐ "Now Assist AI Agents" installed (+ product Now Assist app)
  4. ☐ Now Assist Skill Kit installed (for custom skills)
  5. ☐ AI Search enabled
  6. ☐ Now Assist / Otto Panel enabled
  7. ☐ Admin roles assigned (next lesson)
Mental model: Think of it as three layers stacking up — License (permission to use Now Assist) → Plugins (the AI Agents + Skill Kit software) → Platform features (AI Search + the panel that surfaces agents). All three must be in place.
