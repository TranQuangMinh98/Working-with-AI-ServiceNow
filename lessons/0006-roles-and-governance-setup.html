Lesson 6: Roles & Governance Setup

Duration: 12 minutes | Level: Beginner | Prerequisites: Lesson 5

Learning Objective

Assign the roles needed to build agents, and understand the governance guardrails that keep agents safe from day one.

The Roles You Need

Role Grants
sn_aia.admin Administer AI Agent Studio — create/manage agents and workflows.
sn_skill_builder.admin Build custom skills in the Now Assist Skill Kit (Unit 5).
sn_skill_builder.viewer View (read-only) NASK skills.

To assign a role: as an admin, open the target user record and add the role (e.g. sn_aia.admin), or add it via a group. Then have that user refresh — AI Agent Studio should now appear in their navigator.

⚠ Least privilege: Grant building roles only to the people who design agents. End users who merely talk to agents don't need these admin roles — they interact through a channel like the Otto Panel.

Governance Guardrails (Know These Early)

ServiceNow bakes safety into the platform. You'll use these throughout the course, but meet them now:

  • Deny-by-default ACL — agents can only access what you explicitly allow
  • Run-as identity — an agent acts as a defined identity, bounded by that identity's permissions
  • Role masking — restrict which roles/data the agent effectively sees
  • Kill Switch — instantly stop a misbehaving agent
  • Now Assist Guardian — monitors generative behavior
  • AI Control Tower — central place to discover, govern, and observe all AI (Lesson 18)
Security mindset: An agent is only as powerful as the identity and tools you give it. Set up least-privilege access before building, not after. Governance isn't a final step — it's the frame you build inside from the start.
Best practice from the field: Always deploy agents under the AI Control Tower rather than as unmanaged automation, so every agent is discoverable and governable. We'll do this hands-on in Lesson 18.
You've finished Unit 2! Your instance is entitled, plugins installed, Studio accessible, roles assigned, and you know the guardrails. Next, Unit 3 explores what agents can do and tours the pre-built ones — then Unit 4 is your first build.
