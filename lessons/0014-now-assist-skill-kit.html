Lesson 14: Custom Skills with the Now Assist Skill Kit

Duration: 18 minutes | Level: Intermediate | Prerequisites: Lesson 13

Learning Objective

Understand what the Now Assist Skill Kit (NASK) is, build a custom generative skill step-by-step, and learn how to attach that skill to an AI agent as a tool.

What Is a Skill?

A Skill is a single, prompt-driven generative capability. It takes a configured prompt (plus optional inputs and grounding data), sends it to an LLM, and returns generated output. Think of it as a reusable "generative building block."

Skills vs. Agents: A skill is one generative action (e.g., "summarize this incident"). An agent reasons and plans across many tools — and a skill can be one of those tools. Skills are building blocks; agents orchestrate them.

Prerequisites (Verify First)

  • Active Now Assist license
  • Instance on Xanadu or later
  • The Now Assist Skill Kit plugin installed
  • Role sn_skill_builder.admin (builder) or sn_skill_builder.viewer
⚠ NASK is NOT available on PDIs (Personal Developer Instances). You'll need an enterprise instance with Now Assist entitlements to build skills. (NASK FAQ)

Building a Skill: Step by Step

Here's the verified click-path to build a custom skill: (ServiceNow — Creating a Custom Skill, Part 1)

  1. Go to All > Now Assist Skill Kit > Home, click Create skill.
  2. Enter a Name and Description.
  3. Select provider Now LLM Service and Provider API Now LLM Generic (or choose a third-party LLM via BYOK).
  4. Author the prompt — write your own, pick from the library, or use an AI-generated draft. Then click Use prompt > Next.
  5. Define inputs with + Add (typed, e.g. strings). Use descriptive input names — the agent uses them to populate values.
  6. Review the Skill outputs tab, then Go to Summary > Finish.
  7. (Optional) Add tool nodes inside the skill — like a Retriever (RAG) node — to ground the prompt in real data.
  8. Test via the Test prompt panel, then publish and activate the skill in the Now Assist Admin console.

Attaching a Skill to an Agent

Once your skill is published and activated, it can be added to an AI agent as a "Now Assist skill" tool. The agent's orchestrator will call it like any other tool.

⚠ Order matters: A skill must be published and activated in the Now Assist Admin console before it can be attached to an agent. If you can't find your skill in the tool picker, this is usually why.
Debugging tip: When testing a skill, inspect the Grounded prompt tab (the final prompt actually sent to the LLM, with data filled in) and the Tools tab. These reveal exactly what the model saw.
