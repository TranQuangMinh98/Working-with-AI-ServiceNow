Lesson 9: Anatomy of an Agent

Duration: 12 minutes | Level: Beginner | Prerequisites: Unit 3

Learning Objective

Learn the anatomy of every AI agent: its four mandatory fields and — most importantly — the three identity fields that separate scope, identity, and behavior.

Four Mandatory Fields

Every agent (stored in the sn_aia_agent table) requires four fields:

  • name — a clear, specific label
  • description — its scope
  • agentRole — its identity
  • securityAcl — its access controls

The Three Identity Fields — Keep Them Separate

This is the single most useful mental model for building good agents. Three fields answer three different questions (Fluent SDK):

description
"What problem
do I solve?"
= SCOPE
agentRole
"Who
am I?"
= IDENTITY
instructions
"How should
I act?"
= BEHAVIOR
Why separate them? Mixing scope, identity, and behavior into one blob confuses the reasoning engine. Clean separation makes the agent predictable and easy to debug. When output is wrong, you know which field to fix.

A Worked Example: "IT Password Helper"

name:        IT Password Helper

description: Helps employees regain access to
             accounts by resetting passwords and
             unlocking accounts. (SCOPE)

agentRole:   You are a friendly IT support
             specialist focused on account access.
             (IDENTITY)

instructions: 1. Verify the user's identity first.
              2. Confirm which account is affected.
              3. Use the reset-password tool only
                 after identity is confirmed.
              4. NEVER reset without confirmation.
              (BEHAVIOR)

What Else an Agent Has

  • Tools — its capabilities (Unit 5)
  • Trigger — what launches it (or none)
  • Channels — where users reach it
  • Security controls — ACLs, run-as identity, role masking
Design principle: Keep each agent focused on one capability. If it starts needing more than ~5 tools or juggling unrelated jobs, that's your signal to split it into multiple agents (Unit 6).
