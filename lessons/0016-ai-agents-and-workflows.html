Lesson 17: AI Agents + Flow / Workflow Studio

Duration: 15 minutes | Level: Intermediate | Prerequisites: Unit 5

Learning Objective

See how AI Agents and traditional ServiceNow flows work together — agents calling flows as tools, and flows calling generative skills — so you can combine deterministic automation with AI reasoning.

Two Worlds, Better Together

ServiceNow has two complementary automation styles. The magic is combining them:

Flows
deterministic

Reliable, repeatable, rule-based. Same input → same output, every time.

AI Agents
reasoning

Flexible, adaptive, understands natural language. Handles the unexpected.

Direction 1: Agents Call Flows

Any subflow or flow action built in Workflow Studio can be wrapped as a tool that an agent calls. This lets an agent hand off well-defined, multi-step work to reliable automation.

The String rule (again): A subflow/flow action used as a tool must have String inputs and outputs. If your flow uses other types, the orchestrator can't pass data to it. Wrap or convert values to String at the flow boundary.

Example: An agent understands "onboard my new hire Jai starting Monday," extracts the details through conversation, then calls a deterministic Employee Onboarding subflow that provisions accounts, orders a laptop, and books training — reliably, every time.

Direction 2: Flows Call Skills

The reverse also works. A NASK skill can be deployed as a Flow Action, so a traditional flow can invoke generative AI mid-process. The skill's output comes back as JSON:

// Parsing a skill's output inside a flow script step
var result = JSON.parse(
  fd_data._1__execute_skill.output.response
).model_output;

Example: A flow triggered on new incidents calls a "summarize incident" skill, writes the summary to a field, then continues with normal routing logic.

How to choose the direction: If the entry point is a conversation or an ambiguous request → lead with an agent that calls flows. If the entry point is a structured, record-triggered process that just needs a spot of AI → lead with a flow that calls a skill.
⚠ Integration Hub note: Integration Hub spokes can also be surfaced as agent tools, letting agents reach external systems. Remember these still run under the agent's security context.
