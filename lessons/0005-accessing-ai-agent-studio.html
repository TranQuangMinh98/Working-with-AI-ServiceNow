Lesson 5: Accessing AI Agent Studio

Duration: 10 minutes | Level: Beginner | Prerequisites: Lesson 4

Learning Objective

Find your way into AI Agent Studio, understand its main areas, and know how it differs from Now Assist.

What Is AI Agent Studio?

AI Agent Studio is the workspace where you create, configure, test, and deploy AI agents and agentic workflows. It's your home base for everything in Units 4–6.

Studio vs. Now Assist — don't confuse them:
  • Now Assist = the broader generative-AI product family (skills, summarization, Q&A) that surfaces AI to end users.
  • AI Agent Studio = the specific builder tool where you design and manage autonomous agents.
Agents build on the Now Assist foundation; the Studio is where you assemble them.

How to Open It

Once plugins are installed and you have the right role (next lesson):

  1. In the platform navigator, filter for AI Agent Studio.
  2. Go to All > AI Agent Studio > Overview for the landing/home page.
  3. To build, go to All > AI Agent Studio > Create and manage > AI agents (or Agentic workflows).

The Main Areas You'll Use

Overview Landing page — status, entry points, and pre-built agents.
Create and manage > AI agents Where you build and edit individual agents.
Create and manage > Agentic workflows Where you compose multiple agents (Unit 6).
Testing interface Run agents, watch the chain of thought (Lesson 15).
Can't see AI Agent Studio in the navigator? The two usual causes: (1) the plugins from Lesson 4 aren't installed, or (2) your user is missing the sn_aia.admin role — which is exactly what we set up in the next lesson.
