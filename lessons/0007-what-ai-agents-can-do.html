Lesson 7: What AI Agents Can Do

Duration: 12 minutes | Level: Beginner | Prerequisites: Unit 2

Learning Objective

Map the real capabilities of ServiceNow AI agents to concrete outcomes — so you can spot good agent opportunities in your own organization.

The Capability Spectrum

AI agent capability grows with the tools you give it. Think of three tiers:

Tier 1: Inform
look up & explain
→
Tier 2: Act
create & update records
→
Tier 3: Orchestrate
multi-step workflows

Tier 1 — Inform (read-only, safest)

  • "What are my open incidents?" → looks up and summarizes
  • "What's the expense reimbursement process?" → retrieves from knowledge (RAG)
  • "Show critical servers in the Chicago datacenter" → queries the CMDB

Tier 2 — Act (create/update, needs guardrails)

  • Create an incident from a natural-language description
  • Update a ticket's priority or add a work note
  • Categorize and route an incident to the right group

Tier 3 — Orchestrate (multi-agent workflows)

  • Triage a case → investigate → draft a resolution (a chain of agents)
  • Onboard a new hire: provision access, order hardware, schedule training
  • End-to-end incident lifecycle: categorize → investigate → resolve → wrap up
The pattern: Capability = reasoning (the LLM) + tools (what it can touch) + orchestration (how agents combine). You unlock higher tiers by adding tools and composing agents — which is exactly what Units 5 and 6 teach.

Match the Tier to the Risk

⚠ Higher tier = higher stakes. Tier 1 (read) is nearly always safe to run autonomously. Tiers 2 and 3 touch or change data, so they need supervised execution, tight ACLs, and careful testing. Start users on Tier 1 wins, then earn trust upward.

Spotting a Good Agent Opportunity

A task is a strong AI-agent candidate when it:

  • Arrives as natural language (not a rigid form)
  • Needs context or judgment to handle well
  • Involves several steps a human would otherwise stitch together
  • Happens often enough to be worth automating

If a task is high-volume, identical every time, and needs zero judgment — a traditional flow is the better tool (recall Lesson 1).
